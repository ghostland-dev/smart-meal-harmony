# SmartMealPlanner

Meal planning for medical constraints (neuropathy, diabetes).

## Features

- Meal planning
- Profile and dashboard
- Supabase back-end

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Supabase

## Getting Started

```bash
git clone https://github.com/ghostland-dev/smart-meal-harmony.git
cd smart-meal-harmony
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
